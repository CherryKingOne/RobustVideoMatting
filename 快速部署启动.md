# 快速部署启动

## 1. 安装依赖

```bash
uv sync
```

## 2. 下载模型

将模型下载到 `models/` 目录中：

```bash
wget https://github.com/PeterL1n/RobustVideoMatting/releases/download/v1.0.0/rvm_mobilenetv3.pth -P models/
```

# 运行
```
uv run inference.py \
  --variant mobilenetv3 \
  --checkpoint "models/rvm_mobilenetv3.pth" \
  --device "cuda" \
  --input-source "data/input/T001_清源_动作_C3604_前3s.mp4" \
  --output-type video \
  --output-composition "data/output/output_composition.mp4" \
  --output-alpha "data/output/output_alpha.mp4" \
  --output-foreground "data/output/output_foreground.mp4" \
  --downsample-ratio 0.4

```
